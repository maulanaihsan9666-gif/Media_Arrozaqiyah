DESKRIPSI
---------
Website Pondok Pesantren Arrozqiyah merupakan website
profil pesantren dengan tampilan modern, elegan,
responsif, dan bernuansa Islami.

FITUR WEBSITE
-------------
1. Halaman Beranda
2. Profil Pondok Pesantren
3. Visi dan Misi
4. Program Pendidikan
5. Jadwal Kegiatan Harian Santri
6. Kegiatan Pesantren
7. Galeri Foto dengan Lightbox
8. Formulir Pendaftaran Santri Baru
9. Lokasi Google Maps
10. Informasi Kontak
11. Tombol WhatsApp
12. Link Media Sosial
13. Animasi Scroll
14. Tombol Back to Top
15. Tampilan Responsif HP, Tablet, dan Laptop

STRUKTUR FOLDER
---------------
pondok-pesantren-arrozqiyah/
|
|-- index.html
|-- style.css
|-- script.js

TEKNOLOGI YANG DIGUNAKAN
------------------------
1. HTML5
2. CSS3
3. JavaScript
4. Google Maps Embed
5. Unsplash (gambar ilustrasi)

CARA MENJALANKAN WEBSITE
------------------------
1. Buat folder bernama pondok-pesantren-arrozqiyah.
2. Masukkan semua file website ke dalam folder.
3. Pastikan nama file tidak berubah.
4. Buka file index.html menggunakan browser.
5. Website siap digunakan.

PENGATURAN WEBSITE
------------------
Sebelum website dipublikasikan, lakukan pengaturan:

1. Nomor WhatsApp
   Buka script.js dan ganti nomor WhatsApp contoh
   dengan nomor resmi Pondok Pesantren Arrozqiyah.

2. Google Maps
   Buka index.html dan ganti alamat iframe Google Maps
   dengan lokasi pesantren yang sebenarnya.

3. Informasi Pesantren
   Sesuaikan alamat, email, nomor telepon, dan
   media sosial dengan informasi resmi pesantren.

4. Foto Galeri
   Ganti foto ilustrasi dengan foto asli pesantren,
   santri, kegiatan, dan fasilitas.

CATATAN
-------
Formulir pendaftaran saat ini mengirimkan data
melalui WhatsApp. Data belum disimpan ke database.

Untuk menyimpan data pendaftar secara otomatis,
diperlukan backend dan database tambahan.
